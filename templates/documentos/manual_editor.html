1. Documentos, versiones y roles

En este módulo, un documento es el registro de un documento legal. Puede contener varias versiones, cada una con su propio archivo PDF y fecha de aprobación.

Documento legal
  • Versión 1
  • Versión 2
  • Versión 3
Lector
Consulta y descarga las versiones publicadas de los documentos a los que tiene acceso.
Editor
Administra los documentos y sus versiones: crea, edita, publica y gestiona la papelera. Este manual está dirigido a ese rol.
Vigencia
Indica cuál es la versión vigente del documento.
Publicación
Permite que los lectores consulten una versión, de acuerdo con los accesos configurados. Un documento puede tener varias versiones publicadas.
Subir un archivo crea un borrador. No lo publica automáticamente. Puede procesarlo con IA o desmarcar esa opción para omitir la lectura. La publicación se gestiona desde Acciones → Publicar.

2. Crear un documento

  1. Pulse Crear, en la parte superior derecha del módulo.
  2. Complete los campos obligatorios: Título del documento, Fecha de aprobación y archivo PDF. El título no debe estar repetido.
  3. Si lo necesita, añada una descripción y palabras clave que ayuden a identificar el documento.
  4. Revise los campos de perfiles, grupos y período: definen quiénes pueden acceder al documento.
  5. Pulse Crear y revise el mensaje de confirmación.

La fecha de aprobación debe estar entre el 1 de enero de 1984 y la fecha actual. El PDF debe contener texto extraíble suficiente; un archivo compuesto únicamente por imágenes puede ser rechazado.

Si mantiene activa la opción de procesamiento, la lectura de IA se realiza en segundo plano. Revise su resultado antes de publicar.

3. Editar un documento

  1. Busque el documento y abra Acciones → Editar.
  2. Seleccione la versión que desea revisar. El formulario muestra su PDF y los datos asociados.
  3. Actualice los campos necesarios, como el título, la descripción, las palabras clave, la fecha de aprobación o los accesos.
  4. Cuando la opción esté habilitada, puede cambiar el estado de la versión o reemplazar su archivo PDF.
  5. Pulse Guardar y compruebe el resultado.
Para conservar el archivo anterior como parte del historial, utilice Agregar nueva versión en lugar de reemplazar el PDF de una versión existente.

4. Agregar una nueva versión

  1. Abra Acciones → Agregar nueva versión en el documento correspondiente.
  2. Seleccione el nuevo PDF e indique su fecha de aprobación; ambos campos son obligatorios.
  3. Puede incluir una descripción del cambio. Si la deja vacía, se utilizará el texto «Nueva version».
  4. Pulse Procesar y revise la confirmación y el estado de lectura de IA.

Al agregarla, la nueva versión queda en borrador y se analiza con IA. La versión vigente anterior y las publicaciones existentes se conservan hasta que usted cambie la publicación.

5. Revisar la lectura de IA

El módulo muestra el estado del análisis: Pendiente, Leído, No leído o Error.

Si el análisis falla, revise el mensaje y utilice Acciones → Reintentar lectura IA cuando esté disponible. El reintento analiza la última versión disponible, incluido un borrador; espere a que termine antes de volver a intentarlo.

Para publicar una versión que aún no está publicada, su lectura de IA debe ser positiva o haberse omitido expresamente al crearla. Si permanece en error o no leído, revise que el PDF tenga texto legible y atienda el mensaje del sistema.

6. Publicar versiones

  1. Abra Acciones → Publicar.
  2. Marque las versiones que desea hacer visibles para los lectores. Puede seleccionar una o varias, siempre que cumplan la validación de IA.
  3. Desmarque las versiones cuya publicación quiera retirar.
  4. Pulse Guardar.

También puede usar Quitar publicación de todas las versiones para retirar la publicación del documento completo.

Al guardar la publicación, el módulo establece como vigente la versión publicada con el número de versión más alto. Publicar no elimina las otras versiones del historial.

7. Enviar a la papelera

Primero retire la publicación. Para eliminar una versión, quite su publicación. Para eliminar el documento completo, quite la publicación de todas sus versiones. No basta con cambiar la vigencia.
  1. Abra Acciones → Eliminar.
  2. Elija eliminar el documento completo o una versión específica, si la opción está disponible.
  3. Si eligió una versión, selecciónela. Las versiones publicadas no se pueden seleccionar.
  4. Opcionalmente, escriba el motivo de eliminación y confirme con Eliminar.

Esta acción envía el contenido a la papelera, donde puede restaurarlo. Si solo queda una versión activa, utilice la eliminación del documento completo.

8. Restaurar o eliminar definitivamente

Abra Papelera desde la cabecera del módulo. Allí encontrará las versiones eliminadas y sus datos.

  • Restaurar: recupera el documento o las versiones seleccionadas. Después, revise su vigencia y publicación en el listado.
  • Eliminar definitivamente: retira el contenido de forma permanente. Revise con cuidado lo seleccionado antes de confirmar: no podrá recuperarlo desde la papelera.
  • Registro de eliminaciones: permite consultar el historial de eliminaciones registrado por el módulo.

9. Consultar y descargar

  1. Localice el documento mediante la búsqueda o los filtros del listado.
  2. Abra Ver documento para acceder al visor.
  3. Seleccione la versión que desea consultar y utilice la opción de descarga del visor.

El lector solo puede consultar versiones publicadas y permitidas por sus accesos. El editor puede revisar también las versiones no publicadas para administrarlas.
